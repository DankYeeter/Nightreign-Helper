# T-043 - Die Katalysator-Konstante C finden: Zauber-/Anrufungsskalierung der Staebe und Siegel (qa-engineer)

Erstellt: 2026-09-03, parallele Session "Nightreign Helper Scaling Questions"
Rolle: qa-engineer (Folgemessung zu T-038, opus)

**Ziel:** Die Stelle in den Spieldaten finden, aus der die im Spiel
angezeigte Skalierungszahl eines Stabes oder Siegels folgt - damit das
Programm Katalysatoren nach der richtigen Kennzahl reihen kann (QA-099).

## Kontext

Quittung aus T-038, Abschnitt 8: Fuer die 28 Katalysatoren (`wep_type` 57
Staebe, 61 Siegel) zeigt das Spiel **nicht** die physische AR, sondern

    Anzeige = C x (1 + Kurve16(INT bzw. FAI) / 100)

mit einer **waffeneigenen Konstante C** (Recluse's Staff 76,1, Astrologer's
Staff 91,4, Glintstone Staff 89,7, Erdtree Seal 121,4, Frenzied Flame Seal
126,1; Carian Regal Scepter ~145). Die RPS-Zahl ("Scaling" 78-145) ist
dasselbe C, um 1/0,973 groesser. C steht in **keinem** numerischen Feld von
EquipParamWeapon: Recluse's Staff und Astrologer's Staff sind dort in allen
Zahlenfeldern identisch (attackBasePhysics 25, correctMagic 100, weight 1,0)
und unterscheiden sich nur in IDs - `behaviorVariationId`, `swordArtsParamId`,
`attackElementCorrectId`, `equippedSpell_R1/R2`, `reinforceTypeId`. Staerkste
Korrelationen zur Fan-Zahl: `rarity` (r = 0,965), `throwAtkRate` (r = 0,940) -
Stellvertreter, keine Traeger.

Heutige Folge: das Programm reiht Rotten Crystal Staff (phys. AR 67,8) vor
Carian Regal Scepter (37,1), das Spiel umgekehrt (182 vs 237). Echte
Fehlreihung. Der Nutzer will Groessenordnung (+-10 %).

## Umfang

1. **ReinforceParamWeapon zuerst.** Die 28 Katalysatoren haben verschiedene
   `reinforceTypeId`. Fuer jeden die Basiszeile (und die Folgezeilen) lesen:
   `correctMagicRate`, `correctFaithRate`, `magicAtkRate`, alle weiteren
   Raten. Pruefen, ob C = f(EquipParamWeapon-Feld x Reinforce-Rate) fuer
   alle 28 gilt - das ist die billigste Hypothese, weil es das einzige
   Unterscheidungsmerkmal ist, das eine Zahl traegt.
2. **AttackElementCorrectParam.** Die `attackElementCorrectId` der 28
   pruefen: tragen die Zeilen Einfluss-/Korrekturwerte, aus denen C folgt?
3. **Elden-Ring-Wissen als Hypothese, nicht als Zahl:** in Elden Ring ist
   die "Sorcery Scaling" eines Stabes 100 x (1 + correctMagic/100 x
   Kurve(INT)/100)-artig aus denselben Params; wenn Nightreign das
   beibehaelt, muss C aus `correctMagic` (bzw. `correctFaith`) x einer
   Reinforce-Rate x ggf. dem Raritaets-Multiplikator folgen. Nachrechnen.
4. Falls 1-3 leer: Suche ueber **alle** Param-Tabellen nach Zeilen, die die
   28 Katalysator-IDs (oder ihre `behaviorVariationId`/`swordArtsParamId`)
   referenzieren und einen Wert innerhalb von 4 % eines C tragen.

**Erfolgskriterium:** eine Formel, die C fuer mindestens 25 der 28
Katalysatoren auf +-3 % trifft, mit Herkunft jedes Faktors - oder die
Negativliste der durchsuchten Tabellen mit Feldzahl.

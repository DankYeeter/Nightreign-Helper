## Was `KeyError: '15'` sein koennte — und warum du das selbst entscheidest

`'15'` ist eine **Zeichenkette**, kein `int`. In diesem Projekt sind Helden-
und Kelch-Kennungen Zahlen; ein Schluessel `'15'` deutet auf eine Stelle, an
der eine Kennung als Text durch einen Datensatz laeuft. **Der Berater fragt
den Datensatz je Ladevorgang** (`relic_scan_mode`, `advisor_cases`,
`game_data`-Fixture). **Aber das ist meine Vermutung, nicht dein Auftrag** —
sie steht hier, damit du sie widerlegen kannst, nicht damit du ihr folgst.

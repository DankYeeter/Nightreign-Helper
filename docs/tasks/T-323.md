## T-323a researcher — genau eine Frage
**Wie kommen aus regulation.bin (Nightreign) je Zauber und je Waffenkunst
Schadensart und Grundwert, und mit welchen Faktoren wird daraus der Treffer?**
Kette Magic.refId1..10 / refCategory → Bullet → AtkParam_Pc (Felder
atkPhys/atkMag/atkFire/atkThun/atkDark, Motion Value, isAddBaseAtk,
overwriteAttackElementCorrectId, spEffect), SwordArtsParam → Bullet/AtkParam
fuer Waffenkuenste (`EquipParamWeapon.swordArtsParamId`), Katalysator-
Spell-Power (`CATALYST_DISPLAY_RATE` 90, `weapons._catalyst_scaling`) und die
ER-Formel Schaden = Grundwert x Spell-Power/100 x Raten. Belege aus Paramdex-
Defs (`vendor/Paramdex/NR/Defs/*.xml`), Leseproben aus der eigenen
Installation (Beast Claw, Glintstone Pebble, Wylders Startwaffen-Skill),
Community-Rechner. Bericht `docs/research/R-010.md`.
